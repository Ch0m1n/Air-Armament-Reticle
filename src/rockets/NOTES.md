# Rocket distribution preview

The sampler is shared with the MKTool attack-aircraft modal. It uses matching Rocket projectiles, aircraft variant payloads, formations and both axes of min/max spread. Widths are full extents in game-distance meters (`60 * salvo * spread`); Yamato is rendered at game scale x2 (526 x 77.8 m).

Evidence: 45 attacks / 1,120 planned rocket impact coordinates in three local Korabli 26.11 replays. The Nakhimov, Colossus and Yorktown-stock configurations are 8x4, 3x6 and 6x2 respectively. Yorktown-top remains a distinct configuration.

Each release draws a fresh batch, sorts it laterally and assigns it in formation-X order. A cumulative rounded inner quota is a candidate model consistent with the observed allocation counts, not recovered native client code. The inner region is sampled uniformly; the remaining quota is sampled from the outer ellipse excluding the inner ellipse. Density remains illustrative. Applying the rules to other aircraft or versions is an extrapolation.

This preview registers every release to its own aim center. Center movement, dynamic aiming contraction, build effects, rocket trajectories, collisions and damage are not reconstructed. Timeline positions show the nominal release schedule from the data, not network packet intervals, firing delay or time of impact. Maximum spread uses the theoretical data bounds; the supplied Colossus wide-aim attacks do not establish that it reached the maximum.

Raw replay files, player identifiers and world coordinates are not included in the public assets or fixtures. Fixtures contain only game input parameters and aggregate allocation counts.
