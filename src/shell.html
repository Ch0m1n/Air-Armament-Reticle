Calculation notes

Default speed and time scale. Build effects, terrain and actual game RNG are not reproduced.

Same scale applies within each armament tab. Bombers and airstrikes use meters. Torpedo diagrams share a range axis; horizontal spacing and the enlarged Yamato reference are schematic.

Airstrike flight time is activation to first impact at minimum and maximum range. Release animations are pattern previews, not real-time countdowns. Inner distribution regions are estimates, not hit probability.

Yamato reference: 263 × 38.9 m. No game JSON datasets are bundled with this skeleton.
